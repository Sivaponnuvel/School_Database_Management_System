# 🏫 School Database Management System
A structured and efficient School Database Management System built using SQL.
This project focuses on managing students, teachers, classes, subjects, and attendance using relational database concepts.

---

## 🚀 Features
* 👨‍🎓 Student Records Management
* 👨‍🏫 Teacher & Subject Management
* 📅 Attendance Tracking System
* 🏫 Class-wise Data Organization
* 📊 SQL Query Implementation
* 🔗 Relational Database Design
* 📈 Data Analysis using SQL Queries

---

## 🛠️ Technologies Used
* SQL
* MySQL
* Relational Database Concepts
